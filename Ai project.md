I am building a hackathon project called:

"AI-Powered Industrial Waste Valorization Decision Engine"

Problem:
Industries generate different types of waste, but selecting the most suitable
valorization pathway (reuse, recycling, material recovery, energy recovery,
or disposal) is difficult because the decision depends on waste
characteristics, quantity, contamination, processing cost, transportation,
market demand, and environmental impact.

Build the project incrementally. DO NOT generate the entire application at
once.

For Phase 1, create the complete basic application foundation with:

1. A modern responsive web frontend.
2. Python Flask backend.
3. Clean project structure.
4. A professional industrial/sustainability dashboard design.
5. Navigation:
   - Home
   - Dashboard
   - Register Waste
   - Analysis
   - History
6. A Waste Registration page containing:
   - Waste type
   - Quantity
   - Unit
   - Material composition
   - Contamination level
   - Moisture level
   - Generation frequency
   - Location
   - Processing cost
   - Transportation distance
   - Upload waste image
7. Backend API to receive and validate the waste registration data.
8. Store submitted data temporarily/in a suitable database-ready structure.
9. Add a dashboard with placeholder statistics and charts.
10. Create clean reusable components and modular code.

IMPORTANT:
- Do not implement fake AI predictions yet.
- Do not claim that the system already has a trained ML model.
- Do not use random values to pretend they are AI results.
- Prepare the architecture so that a real Python machine-learning model can
  be integrated in the next phase.
- Keep frontend, backend, ML, and decision-engine modules separated.
- Add comments explaining important parts of the code.
- Make the application runnable locally.
- After implementation, explain:
  a) files created
  b) how to run the application
  c) API endpoints created
  d) where the ML model will be integrated later.
